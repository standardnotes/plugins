# Cypherpunk

A green-phosphor cypherpunk theme for Standard Notes.

Soft mint text on near-black, bright phosphor green for the things you act on, and monospace type everywhere. Colors pass WCAG contrast checks.

Plain CSS that loads nothing from anywhere else (any images are inline `data:` URIs).

- Source, tests and screenshots: https://github.com/nickstruglia/standard-notes-cypherpunk (MIT)
- `src/index.css` is the output of `node scripts/build.mjs` there, version 1.0.1, commit [`37d86e7`](https://github.com/nickstruglia/standard-notes-cypherpunk/commit/37d86e72ed579c7c8c9c47fc80c8896331b9ce83).
